# Session Notes

Public information pages for the **Session Notes** OAuth client — a private,
single-user automation that converts recorded session audio into a written note.

- `index.html` — what the tool is and what it accesses
- `privacy.html` — privacy policy

Published with GitHub Pages, used as the application home page and privacy-policy
link for a personal (single-user, unverified) Google OAuth client.

No application code lives here. All processing happens on privately owned
hardware; nothing is collected by these pages.
