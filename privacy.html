Privacy Policy

Last updated: 31 October 2026

The short version: this is a private tool operated by one person on their own hardware. Your audio and your notes are not sold, shared, published, or sent to any third-party service. The only outside party involved in transport is Google Drive, which is where the file already lives.

Who this covers

“Session Notes” is a personal, non-commercial automation operated by a single individual for their own use. It is not a public service, it has no sign-up, and it has exactly one operator. This policy describes what that tool does with the files placed in its designated Google Drive folder.

What is collected

Only what is placed in the designated folder, and only that:

DataSourcePurpose
Audio recordings you uploadFiles you drop into the shared Drive folderTranscription
The resulting transcriptGenerated locally from your audioSource of truth for the note
The written noteGenerated locally from the transcriptDelivered back to the same folder
File name, size, and timestampProvided by Google DriveOrdering and de-duplicating files

Nothing else is collected. There are no cookies, no analytics, no device identifiers, no location data, and no account records.

Where processing happens

All transcription and summarisation run on a privately owned server on a private home network. The speech-to-text and language models are self-hosted; no prompt, transcript, or audio sample is transmitted to any external AI provider, cloud API, or research service.

Google Drive authorisation

The tool is authorised by the folder owner, for the folder owner's own Google account, using OAuth. It requests Drive access because Google's per-file permission model cannot see files that a different person uploads into a shared folder — so a narrower per-file grant cannot work for this workflow. Despite the breadth of the grant, the automation is scoped in code to one folder: it does not enumerate, read, copy, analyse, or modify any other file in the account.

You can revoke that access at any time at myaccount.google.com/permissions. Revoking it stops the tool from seeing the folder immediately.

Retention and deletion

  • Audio in Google Drive is deleted as soon as it has been transferred for processing. The Drive folder is a delivery mechanism, not a store.
  • The master recording is retained on the operator's own local storage so a transcript can be corrected later, and can be deleted on request at any time.
  • Notes and transcripts remain in the Drive folder under your control. Delete them like any other file and they are gone.

Sharing

No data is sold, rented, traded, published, or disclosed to third parties. No data is used to train models. The only parties who can read the material are you and the operator of the tool — the same two people who could already read the folder.

Security

Files move over authenticated, encrypted connections. Access to the processing server and to the Google credentials is limited to the operator, and credentials are stored on that private server. No system is perfectly secure, so do not place anything in the folder that you would not be comfortable storing on a personal computer.

Children

This tool is not directed at children and collects nothing from anyone beyond the files deliberately placed in the folder.

Changes

If this policy changes, the “last updated” date above changes with it. Because the tool has one operator and no user base, there is no mailing list to notify; the current version always lives at this URL.

Contact

Questions, corrections, or a deletion request: open an issue on the project repository.
