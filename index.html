Session Notes

A private tool that turns recorded session audio into a written note. It runs entirely on hardware the owner controls. There is no service, no account to create, and no data sharing.

In one line: audio lands in a Google Drive folder, a script on a private home server transcribes and summarises it, and a finished document appears back in the same folder.

What it does

  • Watches one designated Google Drive folder for new audio files.
  • Transcribes the speech with a locally hosted speech-to-text model.
  • Produces a short written note plus a verbatim transcript, as a Word document.
  • Returns the document to the same folder and removes the audio copy from Drive, keeping the master recording on the owner's own storage.

What it accesses

The Google Drive authorisation is granted by the owner to their own Drive account, because Google's per-file permission model cannot see files that another person uploads into a shared folder. The automation only ever reads and writes inside the single folder it is pointed at; it does not browse, index, copy or analyse anything else in the account.

What it does not do

  • No third-party services, clouds, or model providers receive the audio or the text.
  • No analytics, advertising, tracking, or telemetry.
  • No accounts, no mailing list, no user data collected by this site.

Who runs it

One person, for their own use, on a single household server. It is not offered to the public and has no other users.
